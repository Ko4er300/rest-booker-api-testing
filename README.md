# Restful Booker API Testing

Тестирование REST API сервиса [Restful Booker](https://restful-booker.herokuapp.com/apidoc/index.html).

## Выполнено

- Позитивные и негативные тест-кейсы для основных API эндпоинтов
- Postman коллекция с автоматическими проверками
- Баг-репорты по обнаруженным дефектам

## Структура

- `test-cases/` — тест-кейсы
- `postman/` — Postman коллекция
- `bug-reports/` — баг-репорты
